latitude / longitude, routes served, entry, vending, entrance type, and
ADA compliance information. For the cleaning steps, I first used
`clean_names()` function to convert the raw column names into
standardized strings. Then, I used the `select()` function to keep only
the variables of interest listed above. Lastly, I used the `mutate()`
function to convert the entry variable from character (YES vs NO) to a
logical variable. The resulting dataset now has 1868 rows and 19
columns. These data are not tidy because the route number served is
stored in the column names instead of in a single variable.
